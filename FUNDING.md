# Funding

OpenCloudMesh Go is built and maintained by Mahdi Baghbani as part of ongoing
work on Open Cloud Mesh (OCM). Building a real, honest OCM peer takes sustained
time, and that time is possible because someone chose to fund open source
infrastructure directly.

Work on this repository is supported by the Sovereign Tech Agency through the
Tech Fund, under the Open Cloud Mesh project, and I am grateful for that
support.
